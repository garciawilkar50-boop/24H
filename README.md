# Pétalos de Reinicio
**Sauce Solitario · RPG narrativo por turnos · Android y PC**

El desarrollo nuevo prioriza una versión web para que el proyecto pueda trabajarse desde un teléfono sin instalar Godot.

## Acto I
La historia incluye Nilo, Tic, Vera, tres pétalos de recuerdo, el Arco de las Raíces, Lenteja, la Raíz Hueca, objetos, decisiones y un cierre con variaciones de ruta.

## Estado honesto
El código del prototipo y la documentación están guardados en la rama `petalos-reinicio`. El arte que aparece en el juego sigue siendo temporal. Canva devolvió un límite de créditos al intentar generar automáticamente el kit visual, así que los recursos deben diseñarse/exportarse manualmente desde la carpeta enlazada. El juego todavía necesita pruebas reales en Chrome Android y GitHub Pages no está confirmado como desplegado. No se ha creado una APK.
