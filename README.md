# Veyro

Interfaz responsive de comunidades y conversaciones con estética oscura, minimalista y sin degradados.

## Requisitos
- Node.js 20 o superior
- npm

## Desarrollo
```bash
npm install
npm run dev
```
Abre http://localhost:3000.

## Estado
Esta entrega incluye interfaz y estados locales de demostración. La autenticación, mensajería real, llamadas, persistencia de comunidades y notificaciones necesitan servicios backend y no se presentan como funciones conectadas.
